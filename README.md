# BudgetingBash
A Mathematical and budgeting operations through BASH Scripts.

In several scripts through TUI the user can perform VAT calculations, follow his VAT for the last set period of time. 
Follow transactions and its balance for the last set period of time.
All the operations are include direct reading and writing to files, containing the upper said information.

This small scripts could be useful in a small linux based storage system or database, for fast small calculations with info from different files.
